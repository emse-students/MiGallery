# MiGallery is a private photo gallery of named students. ONLY the home page may be indexed (user
# decision, 2026-10-06): a presentation and a sign-in button, never a photo, an album or a name.
#
# `Allow: /$` matches the root alone (`$` anchors the end) and the longer rule wins over `Disallow: /`
# in Google's matching, so every album, every API route and every other page stays refused - an
# allowlist of one, where a list of named prefixes would let a NEW route through.
# `X-Robots-Tag: noindex` on every other response is the second voice (see `hooks.server.ts`).
#
# There is deliberately NO sitemap. A sitemap exists to hand a crawler a link graph, and the only
# page worth a crawler's time is the one it already finds. Publishing one would risk being a list of
# album URLs in a file anybody can fetch.
#
# This does NOT make the Open Graph tags dead weight. An unfurler - Discord, Slack, WhatsApp,
# Canari's own link preview - is not a crawler: it fetches the exact URL somebody pasted and never
# reads this file. Sharing an album link is a supported action, so the card it produces is part of
# the product. See docs/wiki/seo.md.

User-agent: *
Allow: /$
Disallow: /
